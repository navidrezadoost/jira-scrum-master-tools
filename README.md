# jira-scrum-master-tools
Scrum Master plugins for team calculation &amp; assessment—no manual math. Covers Sprint metrics (Velocity, Story Points, Scope Change, Commitment Reliability, Spillover, Throughput), forecasting (Velocity, Epic, Monte Carlo, Burn-up, Capacity), and team analysis (Capacity, Availability, Vacation, WIP, Cycle/Lead Time, Aging).
